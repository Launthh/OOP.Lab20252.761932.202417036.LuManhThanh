-What class should implement the Comparable interface?
+Lớp Media nên implement Comparable<Media> vì tất cả Book, DVD, CD đều kế thừa từ Media.
Ví dụ:
	public abstract class Media implements Comparable<Media>
-In those classes, how should you implement compareTo() method to reflect the ordering that we want?

+Nếu sắp xếp theo title rồi đến cost:

public int compareTo(Media other) {
    int titleCompare = this.title.compareTo(other.title);

    if (titleCompare != 0) {
        return titleCompare;
    }

    return Float.compare(this.cost, other.cost);
}

+Nếu sắp xếp theo cost rồi đến title:

public int compareTo(Media other) {
    int costCompare = Float.compare(other.cost, this.cost);

    if (costCompare != 0) {
        return costCompare;
    }

    return this.title.compareTo(other.title);
}

-Can we have two ordering rules of the item if we use Comparable interface approach?
Không thuận tiện.

Comparable chỉ hỗ trợ một cách sắp xếp mặc định thông qua compareTo().

Nếu muốn nhiều cách sắp xếp khác nhau:
+theo title rồi cost
+theo cost rồi title
thì nên dùng Comparator.

-Suppose the DVDs has a different ordering rule from the other media types, that is by title, then decreasing length, then cost. How would you modify your code to allow this?

Nên tạo Comparator riêng cho DVD thay vì dùng chung Comparable.

Ví dụ:

public class DVDComparator implements Comparator<DigitalVideoDisc> {

    @Override
    public int compare(DigitalVideoDisc dvd1, DigitalVideoDisc dvd2) {

        int titleCompare = dvd1.getTitle().compareTo(dvd2.getTitle());

        if (titleCompare != 0) {
            return titleCompare;
        }

        int lengthCompare = Integer.compare(
            dvd2.getLength(),
            dvd1.getLength()
        );

        if (lengthCompare != 0) {
            return lengthCompare;
        }

        return Float.compare(dvd1.getCost(), dvd2.getCost());
    }
}
